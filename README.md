## 🏥 Healthcare Problem

Liver-related diseases can be difficult to identify at an early stage because symptoms may not always be obvious.

Machine Learning can be used to analyze patterns within patient health data and identify relationships between different medical parameters.

This project demonstrates a predictive approach where patient attributes are processed by Machine Learning models to estimate whether the provided data indicates a potential liver disease condition.

> **Important:** The prediction generated by this application is intended for educational and experimental purposes only and must not be considered a medical diagnosis.

## 🧠 Classification Models

Multiple classification algorithms can be used to analyze the patient data.
Logistic Regression
A statistical classification algorithm used as a baseline model for predicting the target class.
K-Nearest Neighbors
KNN predicts a class based on the similarity between a new patient record and existing observations.
Support Vector Machine
SVM identifies a decision boundary that separates different classes in the feature space.
Random Forest
Random Forest combines multiple decision trees to produce a more robust classification model.

## 📈 Performance Evaluation

The Machine Learning models can be evaluated using:
Accuracy
Measures the proportion of correctly classified observations.
Precision
Measures how many observations predicted as positive are actually positive.
Recall
Measures how many actual positive observations were correctly identified.
F1-Score
Provides a combined measure of precision and recall.
Confusion Matrix
Provides a detailed view of correct and incorrect classifications.
